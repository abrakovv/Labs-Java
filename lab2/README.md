# Задание 1

## Задача 1.1. Точка

### Текст задачи

Создать класс `Point`, описывающий точку на плоскости с координатами `x` и `y`. Создать три точки с разными координатами и вывести их на экран.

### Алгоритм решения

1. Создать класс `Point` с приватными полями `x` и `y`.
2. Реализовать конструктор, принимающий координаты точки.
3. Реализовать методы получения координат, метод `moveTo()` для изменения координат и `toString()` для представления точки в текстовом виде.
4. В главном классе запросить у пользователя координаты трёх точек.
5. Проверить ввод координат и не допускать повторения одинаковых точек.
6. Вывести созданные точки на экран.

# Задание 2

## Задача 2.1. Линия и ссылки на точки

### Текст задачи

Создать класс `Line`, который хранит ссылки на начальную и конечную точки. Продемонстрировать, как изменение координат существующей точки влияет на линии, которые ссылаются на неё, и как замена ссылки на новый объект отличается от изменения самого объекта.

### Алгоритм решения

1. Создать класс `Line` с полями `start` и `end` типа `Point`.
2. Реализовать конструктор, методы получения точек, методы замены точек и `toString()`.
3. Создать две линии и третью линию, использующую начальную точку первой линии и конечную точку второй линии.
4. Изменить координаты существующих точек через методы `moveTo()`.
5. Вывести все линии и показать, что изменения объектов-точек отражаются во всех линиях, которые на них ссылаются.
6. Заменить начальную точку первой линии новым объектом `Point` и повторно вывести линии, чтобы показать отличие замены ссылки от изменения исходного объекта.

# Задание 3

## Задача 3.1. Студент и массив оценок

### Текст задачи

Создать класс `Student`, содержащий имя студента и массив оценок. Продемонстрировать совместное использование одного массива несколькими объектами и отличие общего массива от отдельной копии.

### Алгоритм решения

1. Создать класс `Student` с полями `name` и `grades`.
2. Реализовать конструктор, методы получения имени и массива оценок, метод изменения оценки и `toString()`.
3. Запросить имя первого студента и его оценки, проверяя корректность введённых данных.
4. Создать второго студента, передав ему тот же массив оценок, что и первому.
5. Изменить одну оценку через второго студента и вывести обоих студентов, чтобы показать, что общий массив изменился для обоих объектов.
6. Создать третьего студента с копией массива оценок первого студента.
7. Изменить оценку первого студента и вывести данные первого и третьего студентов, чтобы показать независимость отдельной копии массива.

# Задание 4

## Задача 4.1. Неизменяемая точка

### Текст задачи

Создать класс `ImmutablePoint` с неизменяемыми координатами. Продемонстрировать создание нескольких неизменяемых точек и получение точки с другими координатами без изменения исходного объекта.

### Алгоритм решения

1. Создать класс `ImmutablePoint` с полями `x` и `y`, объявленными как `final`.
2. Реализовать конструктор, методы чтения координат и `toString()`. Методы изменения координат не добавлять.
3. Ввести координаты и создать три неизменяемые точки.
4. Вывести созданные точки.
5. Создать новый объект `ImmutablePoint` с другими координатами и вывести оба объекта.
6. Убедиться, что координаты исходной точки остаются прежними.

## Задача 4.2. Линия с неизменяемыми точками

### Текст задачи

Создать класс `ImmutableLine`, который хранит две неизменяемые точки. Реализовать конструкторы для создания линии по двум точкам и по четырём координатам. Продемонстрировать создание линий и получение новой линии с изменённой точкой без изменения исходной.

### Алгоритм решения

1. Создать класс `ImmutableLine` с полями `start` и `end` типа `ImmutablePoint`, объявленными как `final`.
2. Реализовать конструктор, принимающий две точки, и конструктор, принимающий четыре координаты.
3. Реализовать методы получения точек и `toString()`.
4. Создать первую линию по четырём координатам, вторую — по двум объектам `ImmutablePoint`.
5. Создать третью линию, используя начало первой линии и конец второй.
6. Создать новую первую линию с другой начальной точкой.
7. Вывести исходную и новую линии, а также третью линию, чтобы показать, что исходные объекты не изменились.

# Задание 5

## Задача 5.3. Длина линии

### Текст задачи

Создать класс `MeasurableLine`, наследующий `ImmutableLine`, и реализовать метод вычисления длины линии между двумя точками. Результат длины округлять до целого числа.

### Алгоритм решения

1. Создать класс `MeasurableLine`, унаследованный от `ImmutableLine`.
2. Реализовать конструктор, принимающий координаты начала и конца линии.
3. Реализовать метод `length()`, вычисляющий длину по формуле расстояния между двумя точками:

   `L = sqrt((x2 - x1)^2 + (y2 - y1)^2)`

4. Округлить вычисленную длину до ближайшего целого числа.
5. В главном классе запросить координаты двух точек, проверяя корректность числового ввода.
6. Вывести линию, формулу вычисления, подстановку значений, точную длину и округлённый результат.

# Проверка корректности ввода

При вводе координат программа проверяет, что введены конечные числовые значения. Допускается ввод дробной части через точку или запятую. Для оценок проверяется диапазон от 2 до 5, для количества оценок — от 1 до 20, а для номера изменяемой оценки — соответствие диапазону массива. Имена проверяются на непустое значение и допустимые символы. При ошибке программа выводит сообщение и повторно запрашивает данные.
