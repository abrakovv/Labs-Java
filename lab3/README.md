# Задание 1. Инкапсуляция

## Задача 6. Отдельные линии

### Текст задачи
Изменить сущность «Линия». Две любые линии не должны ссылаться на один и тот же объект точки. У линии должна быть возможность изменять координаты начала и конца, а также получать координаты начала и конца.

### Алгоритм решения
Создать класс `Line` с закрытыми полями для начальной и конечной точек. В конструкторе и сеттерах сохранять независимые копии точек, чтобы разные линии не использовали один объект точки. Для получения координат возвращать копии точек. Добавить методы изменения начала и конца линии, метод вычисления длины и `toString()`.

## Задача 12. Квадрат

### Текст задачи
Создать сущность «Квадрат». Квадрат имеет точку левого верхнего угла и длину стороны. Его можно создавать по точке и длине стороны либо по координатам `x`, `y` и длине стороны. Необходимо реализовать строковое представление и получение ломаной, вершины которой соответствуют углам квадрата. Также требуется продемонстрировать создание квадрата с координатами `{5; 3}` и стороной `23`, вывод длины ломаной, перемещение последней точки в `{15; 25}` и повторный вывод длины. Нельзя задавать сторону, равную нулю или отрицательному числу; проверка выполняется и при создании, и при изменении стороны.

### Алгоритм решения
Создать класс `Square` с закрытыми полями верхнего левого угла и длины стороны. Реализовать два конструктора и проверку положительности стороны. Для изменения размера использовать сеттер с такой же проверкой. Метод получения ломаной формирует четыре вершины квадрата в правильном порядке. В `Main` создать квадрат по условию, получить ломаную, вывести её длину, переместить последнюю точку и вывести новую длину.

# Задание 2. Разработка структур данных

## Задача 1. Неизменяемый массив

### Текст задачи
Разработать сущность `ImmutableIntList` — обёртку над массивом целых чисел. Обеспечить создание из массива, набора отдельных чисел и другого списка. Реализовать получение и замену значения по индексу с проверкой границ, строковое представление в квадратных скобках, проверку пустоты, получение размера и возврат массива значений.

### Алгоритм решения
Создать класс с закрытым массивом `int[]`. При создании и при возврате массива выполнять копирование, чтобы внешний код не мог напрямую изменить внутреннее хранилище. Реализовать конструкторы для массива, набора чисел и другого списка. Методы получения и замены элемента проверяют индекс и выбрасывают исключение при выходе за границы. Дополнительно реализовать `size()`, `isEmpty()`, `toArray()` и `toString()`.

# Задание 3. Наследование

## Задача 5. Трёхмерная точка

### Текст задачи
Создать подвид сущности «Точка», который имеет три координаты вместо двух: `X`, `Y` и `Z`.

### Алгоритм решения
Создать класс `Point3D`, унаследованный от `Point2D`. Координаты `x` и `y` хранить в базовом классе, а координату `z` — в классе-наследнике. Добавить конструктор с тремя координатами, геттер и сеттер для `z`, переопределить `toString()`. При изменении координат использовать инкапсулированные методы базового класса.

# Задание 4. Создание иерархий

## Задача 5. Точки

### Текст задачи
Разработать сущности для создания точек с разными характеристиками: одной, двумя или тремя целочисленными координатами, цветом и временем появления. Характеристики могут сочетаться произвольным образом. Необходимо сохранить двухмерную и трёхмерную точки из предыдущей задачи без изменений.

### Алгоритм решения
Создать класс `FlexiblePoint`, который хранит набор координат и дополнительные необязательные характеристики — цвет и время появления. Предусмотреть конструкторы для разных комбинаций параметров. Проверять количество координат и корректность переданных значений. Для вывода объекта переопределить `toString()`. Существующие классы `Point2D` и `Point3D` оставить отдельными.

# Задание 5. Полиморфизм

## Задача 1. Сложение

### Текст задачи
Разработать метод, который принимает набор числовых значений и возвращает их сумму в вещественной форме. Продемонстрировать работу метода на выражениях: `2 + 3/5 + 2.3`; `3.6 + 49/12 + 3 + 3/2`; `1/3 + 1`.

### Алгоритм решения
Создать метод `sum`, принимающий переменное количество числовых аргументов типа `double`. Метод последовательно складывает все переданные значения и возвращает результат. Для дробей передавать результат деления в вещественном формате, чтобы избежать целочисленного деления. В `Main` вызвать метод для всех трёх выражений и вывести результаты.

# Задание 6. Полиморфное сравнение: equals

## Задача 3. Сравнение линий

### Текст задачи
Переопределить метод сравнения объектов `equals()` для сущности «Линия». Две линии считаются одинаковыми, если их начало и конец расположены в одинаковых точках.

### Алгоритм решения
В классе `Line` переопределить `equals()`: проверить, что второй объект не равен `null` и относится к классу `Line`, затем сравнить координаты начальных и конечных точек. Переопределить `hashCode()` так, чтобы равные линии имели одинаковый хэш-код. Проверить сравнение двух линий с одинаковыми координатами и линий с различающимися координатами.

# Задание 7. Пакеты

## Задача 1. Навести порядок

### Текст задачи
Расположить ранее написанные классы по пакетам так, чтобы логически связанные классы находились вместе. Имена пакетов должны иметь не менее трёх частей и соответствовать форме `ru.surname.type`, где вместо `surname` используется фамилия.

### Алгоритм решения
Создать корневую структуру пакетов `ru.abrakov`. Классы распределить по логическим пакетам: `ru.abrakov.geometry`, `ru.abrakov.points`, `ru.abrakov.collections` и `ru.abrakov.main`. Проверить соответствие директив `package` расположению файлов и обновить импорты.

## Задача 2. Главный метод

### Текст задачи
Создать пакет `ru.surname.main` и разместить в нём класс с точкой входа `public static void main`. В этом же пакете расположить класс или интерфейс с методами из блока 2.5. В других пакетах не должно быть классов с точкой входа.

### Алгоритм решения
Создать пакет `ru.abrakov.main`, разместить в нём класс `Main` и метод `public static void main(String[] args)`. В этом же пакете разместить класс `SumUtils` с методом сложения из задания 5.1. Проверить, что метод `main` присутствует только в классе `Main`.

## Задача 3. Возведение в степень

### Текст задачи
Создать метод, принимающий две строки с числами `X` и `Y` и возвращающий результат возведения `X` в степень `Y`. Для преобразования строки использовать `Integer.parseInt`, для возведения в степень — `Math.pow`. Вызвать метод с параметрами командной строки. Для статических методов использовать короткие имена.

### Алгоритм решения
Создать класс `PowerCalculator` с методом возведения в степень. Преобразовать аргументы командной строки в целые числа методом `parseInt`, вычислить результат методом `pow` и обработать ситуацию, когда аргументы отсутствуют или содержат некорректные числа. Использовать статические импорты для короткого обращения к указанным методам. Продемонстрировать запуск с двумя аргументами.

# Задание 8. Пакетная инкапсуляция

## Задача 5. Клонирование линии

### Текст задачи
Переопределить метод клонирования, унаследованный от `Object`, для сущности «Линия». При вызове `clone()` должен возвращаться новый объект линии, значения полей которого являются копиями оригинальной линии.

### Алгоритм решения
Реализовать в классе `Line` интерфейс `Cloneable` и переопределить метод `clone()`. Создавать новый объект линии с новыми объектами начальной и конечной точек, чтобы копия не разделяла изменяемые точки с оригиналом. Проверить клонирование: сравнить исходную линию и копию, затем изменить одну из линий и убедиться, что другая не изменилась.
