# Задание 1. Инкапсуляция

## Задача 6. Отдельные линии

### Текст задачи
Изменить сущность «Линия» так, чтобы две линии не ссылались на один и тот же объект точки. Предусмотреть изменение координат начала и конца линии, а также получение координат этих точек.

### Алгоритм решения
В классе `Line` начальная и конечная точки хранятся в закрытых полях. Конструктор и сеттеры сохраняют копии переданных точек, а геттеры возвращают копии. Поэтому изменение исходной или полученной извне точки не меняет внутреннее состояние линии. В `Main` создаются две линии с общей исходной точкой, после чего исходная точка изменяется и проверяется, что линии сохранили свои координаты.

## Задача 12. Квадрат

### Текст задачи
Создать квадрат с точкой левого верхнего угла и длиной стороны. Предусмотреть два способа создания: по объекту точки и длине стороны либо по координатам `x`, `y` и длине стороны. Реализовать строковое представление и получение ломаной по вершинам квадрата. Сторона должна быть положительной; проверка выполняется при создании и изменении размера.

В демонстрации требуется создать квадрат в точке `{5; 3}` со стороной `23`, получить ломаную, вывести её длину, переместить последнюю точку в `{15; 25}` и снова вывести длину.

### Алгоритм решения
Класс `Square` хранит копию верхнего левого угла и длину стороны. Реализованы оба конструктора, геттеры и сеттер стороны с проверкой положительного значения и допустимости координат. Метод `getPolygonalChain()` создаёт новую ломаную из четырёх вершин квадрата. В `Main` выполняются действия из условия и отдельно проверяются недопустимые значения стороны.

# Задание 2. Разработка структур данных

## Задача 1. Неизменяемый массив

### Текст задачи
Разработать обёртку над массивом целых чисел. Предусмотреть создание из массива, набора отдельных чисел и другого списка. Реализовать получение и замену элемента по индексу с проверкой границ, строковое представление в квадратных скобках, проверку пустоты, получение размера и возврат хранящихся значений в виде стандартного массива.

### Алгоритм решения
Класс `ImmutableIntList` хранит закрытый массив `int[]`. В конструкторе из массива и в конструкторе копирования создаются копии данных. Отдельный конструктор принимает первое число и остальные числа через переменное число аргументов. Методы `get()` и `set()` проверяют индекс. Методы `isEmpty()`, `size()` и `toArray()` возвращают состояние списка и копию массива. Для пустого списка в `Main` можно нажать Enter при вводе первого массива; пустой список создаётся именно из пустого массива.

# Задание 3. Наследование

## Задача 5. Трёхмерная точка

### Текст задачи
Создать подвид сущности «Точка», который имеет три координаты вместо двух: `X`, `Y` и `Z`.

### Алгоритм решения
Класс `Point3D` наследуется от `Point2D`. Координаты `x` и `y` находятся в базовом классе, координата `z` — в классе-наследнике. Добавлены конструктор с тремя координатами, геттер и сеттер для `z`, метод изменения всех трёх координат и переопределённый `toString()`. В `Main` объект также демонстрируется через ссылку типа `Point2D`.

# Задание 4. Создание иерархий

## Задача 5. Точки

### Текст задачи
Разработать сущности для создания точек с одной, двумя или тремя целочисленными координатами, цветом и временем появления. Эти характеристики могут использоваться в любых сочетаниях. Двухмерную и трёхмерную точки из предыдущих задач необходимо сохранить.

### Алгоритм решения
Создан абстрактный класс `AbstractPoint`, который хранит координаты и проверяет их количество. Классы `ColoredPoint`, `TimedPoint` и `ColoredTimedPoint` реализуют точки с цветом, временем или обоими свойствами. Время преобразуется в `LocalTime` и проверяется по формату `ЧЧ:ММ` в диапазоне от `00:00` до `23:59`. В `Main` демонстрируются точка с одной координатой и цветом, точка с тремя координатами и временем, а также точка с двумя координатами, временем и цветом.

# Задание 5. Полиморфизм

## Задача 1. Сложение

### Текст задачи
Разработать метод, принимающий набор числовых значений и возвращающий их сумму в вещественной форме. Продемонстрировать сложение выражений `2 + 3/5 + 2.3`, `3.6 + 49/12 + 3 + 3/2` и `1/3 + 1`.

### Алгоритм решения
В классе `SumUtils` реализован метод `sum()` с переменным числом аргументов типа `double`. Метод проверяет входные значения и складывает их. В `Main` выполняются все три выражения из условия. Для дробей используется вещественное деление.

# Задание 6. Полиморфное сравнение: equals

## Задача 3. Сравнение линий

### Текст задачи
Переопределить метод `equals()` для сущности «Линия». Две линии считаются равными, если их начальные точки совпадают и их конечные точки совпадают.

### Алгоритм решения
В классе `Line` переопределены `equals()` и `hashCode()`. При сравнении проверяется тип объекта, затем сравниваются координаты начала и конца в том же порядке. В `Main` проверяются две линии с одинаковыми координатами и линия с обратным направлением.

# Задание 7. Пакеты

## Задача 1. Навести порядок

### Текст задачи
Распределить классы по логическим пакетам. Имена пакетов должны иметь не менее трёх частей и соответствовать форме `ru.surname.type`.

### Алгоритм решения
Создана структура пакетов `ru.abrakov.collections`, `ru.abrakov.geometry`, `ru.abrakov.points` и `ru.abrakov.main`. Классы размещены по назначению, а импорты соответствуют их пакетам.

## Задача 2. Главный метод

### Текст задачи
Создать пакет `ru.surname.main` и разместить в нём класс с методом `public static void main`. В этом же пакете разместить класс или интерфейс с методами из блока 2.5 и продемонстрировать их работу. В других пакетах не должно быть классов с точкой входа.

### Алгоритм решения
Класс `Main` с единственным методом `main()` и класс `SumUtils` находятся в пакете `ru.abrakov.main`. В демонстрации из `Main` пользователь вводит числа, после чего вызывается `SumUtils.sum()` и выводится результат. Проверено, что метод `main()` находится только в классе `Main`.

## Задача 3. Возведение в степень

### Текст задачи
Создать метод, принимающий две строки с числами `X` и `Y` и возвращающий результат возведения `X` в степень `Y`. Для преобразования строк использовать `Integer.parseInt`, для возведения в степень — `Math.pow`. Вызвать метод с параметрами командной строки и использовать короткие имена статических методов.

### Алгоритм решения
В классе `PowerCalculator` реализован метод `calculate(String x, String y)`. Для преобразования строк применён статический импорт `Integer.parseInt`, для вычисления степени — `Math.pow`. Из `Main` метод вызывается с аргументами командной строки `args`. Если аргументы не переданы, программа запрашивает значения с клавиатуры.

# Задание 8. Пакетная инкапсуляция: package-private, protected

## Задача 5. Клонирование линии

### Текст задачи
Переопределить метод клонирования, унаследованный от `Object`, для сущности «Линия». При вызове `clone()` должен возвращаться новый объект линии, поля которого являются копиями полей оригинала.

### Алгоритм решения
Класс `Line` реализует `Cloneable` и переопределяет `clone()`. Метод создаёт новый объект `Line` с отдельными копиями начальной и конечной точек. В `Main` создаётся копия линии, после чего изменяются координаты копии и проверяется, что исходная линия не изменилась.
