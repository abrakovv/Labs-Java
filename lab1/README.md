# Задание 1. Методы

## Задача 1. Дробная часть
### Текст задачи
Дано вещественное число `x`. Написать метод, который возвращает его дробную часть.
### Алгоритм решения
1. Отбрасываем дробную часть, приведя число к целому типу: `(long) x`.
2. Вычитаем целую часть из исходного числа: `x - (long) x`.
3. Возвращаем результат (например, для 3.75 получим 0.75).

## Задача 2. Сумма последних двух цифр
### Текст задачи
Дано целое число. Написать метод, который возвращает сумму его последних двух цифр.
### Алгоритм решения
1. Последняя цифра — остаток от деления на 10: `x % 10`.
2. Предпоследняя цифра — остаток от деления на 10 числа `x / 10`.
3. Берём каждую цифру по модулю (чтобы работало с отрицательными числами) и складываем.

## Задача 3. Символ в число
### Текст задачи
Дан символ-цифра (от `'0'` до `'9'`). Написать метод, который возвращает соответствующее ему число.
### Алгоритм решения
1. Символы-цифры в таблице кодов идут подряд.
2. Вычитаем код символа `'0'` из кода заданного символа: `x - '0'`.
3. Результат — число от 0 до 9.

## Задача 4. Положительное число
### Текст задачи
Дано целое число. Написать метод, который возвращает `true`, если число положительное, иначе `false`.
### Алгоритм решения
1. Сравниваем число с нулём: `x > 0`.
2. Возвращаем результат сравнения (ноль положительным не считается).

## Задача 5. Двузначное число
### Текст задачи
Дано целое число. Написать метод, который возвращает `true`, если число двузначное, иначе `false`.
### Алгоритм решения
1. Берём модуль числа, чтобы отрицательные числа тоже подходили.
2. Проверяем, что оно лежит в диапазоне от 10 до 99 включительно.

# Задание 2. Условия

## Задача 1. Модуль числа
### Текст задачи
Дано целое число. Написать метод, который возвращает его модуль, не используя `Math.abs`.
### Алгоритм решения
1. Если число меньше нуля — возвращаем число с противоположным знаком `-x`.
2. Иначе возвращаем число без изменений.

## Задача 2. Безопасное деление
### Текст задачи
Даны два целых числа `x` и `y`. Написать метод, который возвращает результат деления `x` на `y`. При делении на ноль вывести сообщение об ошибке и вернуть 0.
### Алгоритм решения
1. Если `y == 0` — выводим сообщение «Деление на ноль невозможно» и возвращаем 0.
2. Иначе приводим `x` к `double` и делим на `y`, чтобы получить дробный результат.

## Задача 3. Тридцать пять
### Текст задачи
Дано целое число. Написать метод, который возвращает `true`, если число делится на 3 или на 5, но не делится на оба сразу (то есть не делится на 15).
### Алгоритм решения
1. Проверяем делимость на 3 и на 5 через остаток от деления (`x % 3 == 0`, `x % 5 == 0`).
2. Если делится на оба — возвращаем `false`.
3. Иначе возвращаем `true`, если делится хотя бы на одно из них.

## Задача 4. Строка сравнения
### Текст задачи
Даны два целых числа `x` и `y`. Написать метод, который возвращает строку вида `x < y`, `x > y` или `x == y` в зависимости от их соотношения.
### Алгоритм решения
1. Если `x < y` — возвращаем строку с знаком `<`.
2. Если `x > y` — возвращаем строку с знаком `>`.
3. Иначе числа равны — возвращаем строку с знаком `==`.

## Задача 5. Тройной максимум
### Текст задачи
Даны три целых числа. Написать метод, который возвращает наибольшее из них.
### Алгоритм решения
1. Считаем максимумом первое число.
2. Если второе число больше максимума — запоминаем его.
3. Если третье число больше максимума — запоминаем его.
4. Возвращаем максимум.

# Задание 3. Циклы

## Задача 1. Числа подряд
### Текст задачи
Дано целое число `x`. Написать метод, который возвращает строку с числами от 0 до `x` через пробел.
### Алгоритм решения
1. Создаём пустую строку.
2. В цикле `for` от 0 до `x` добавляем к строке каждое число и пробел.
3. Удаляем лишний пробел в конце и возвращаем строку.

## Задача 2. Числа наоборот
### Текст задачи
Дано целое число `x`. Написать метод, который возвращает строку с числами от `x` до 0 через пробел.
### Алгоритм решения
1. Создаём пустую строку.
2. В цикле `for` идём от `x` вниз до 0 (шаг −1) и добавляем числа в строку.
3. Удаляем лишний пробел в конце и возвращаем строку.

## Задача 3. Чётные числа
### Текст задачи
Дано целое число `x`. Написать метод, который возвращает строку с чётными числами от 0 до `x` через пробел.
### Алгоритм решения
1. Создаём пустую строку.
2. В цикле `for` идём от 0 до `x` с шагом 2 — так попадаются только чётные числа.
3. Добавляем числа в строку, убираем лишний пробел и возвращаем результат.

## Задача 4. Степень
### Текст задачи
Даны целые числа `x` и `y`. Написать метод, который возвращает `x` в степени `y`, не используя `Math.pow`.
### Алгоритм решения
1. Заводим результат `r = 1`.
2. Повторяем `y` раз: умножаем `r` на `x`.
3. Возвращаем `r`.

## Задача 5. Длина числа
### Текст задачи
Дано целое число. Написать метод, который возвращает количество цифр в числе.
### Алгоритм решения
1. Заводим счётчик `c = 0`.
2. В цикле `do-while` делим число на 10 (отбрасываем последнюю цифру) и увеличиваем счётчик.
3. Повторяем, пока число не станет равным 0.
4. Возвращаем счётчик (цикл `do-while` гарантирует, что для числа 0 ответ будет 1).

# Задание 4. Массивы

## Задача 1. Первое вхождение
### Текст задачи
Дан массив целых чисел и число `x`. Написать метод, который возвращает индекс первого вхождения `x` в массив, или −1, если такого числа нет.
### Алгоритм решения
1. Проходим по массиву от начала к концу.
2. Если текущий элемент равен `x` — сразу возвращаем его индекс.
3. Если дошли до конца и не нашли — возвращаем −1.

## Задача 2. Последнее вхождение
### Текст задачи
Дан массив целых чисел и число `x`. Написать метод, который возвращает индекс последнего вхождения `x` в массив, или −1, если такого числа нет.
### Алгоритм решения
1. Проходим по массиву от конца к началу.
2. Если текущий элемент равен `x` — сразу возвращаем его индекс.
3. Если не нашли — возвращаем −1.

## Задача 3. Максимум по модулю
### Текст задачи
Дан массив целых чисел. Написать метод, который возвращает элемент с наибольшим модулем (со своим исходным знаком).
### Алгоритм решения
1. Считаем лучшим первый элемент массива.
2. Проходим по остальным элементам и сравниваем их модули с модулем лучшего.
3. Если модуль текущего элемента больше — запоминаем его как лучший.
4. Возвращаем лучший элемент.

## Задача 4. Вставка одного элемента
### Текст задачи
Дан массив, число `x` и позиция `pos`. Написать метод, который возвращает новый массив с числом `x`, вставленным на позицию `pos`.
### Алгоритм решения
1. Создаём новый массив длиной на 1 больше исходного.
2. Копируем в него элементы до позиции `pos`.
3. На позицию `pos` записываем `x`.
4. Остальные элементы исходного массива копируем со сдвигом на 1 вправо.

## Задача 5. Вставка массива
### Текст задачи
Даны два массива и позиция `pos`. Написать метод, который возвращает новый массив, в котором второй массив вставлен в первый на позицию `pos`.
### Алгоритм решения
1. Создаём новый массив длиной, равной сумме длин обоих массивов.
2. Копируем в него элементы основного массива до позиции `pos`.
3. Затем копируем все элементы вставляемого массива.
4. Остальные элементы основного массива копируем со сдвигом на длину вставляемого массива.
